# נופשים - אתר להשכרת דירות נופש
תאור הפרויקט:
הפרויקט מציע אתר המיועד לפרסום דירות נופש פרטיות. האתר מציע למשתמשים מגוון אפשרויות חיפוש וניהול דירות, וכולל את הפיצ'רים הבאים:

למשתמשים:

צפייה בכל הדירות: המשתמשים יכולים לצפות במבחר דירות נופש, עם אפשרות לסנן את התוצאות לפי קריטריונים כמו אזור, מחיר, ומספר מיטות.

צפייה בפרטי דירה: הצגת פרטי הדירה המלאים, כולל פרטי התקשרות עם המפרסם. כל זאת ללא הצורך בהתחברות למערכת.

למפרסמים:

התחברות לאזור האישי: המפרסמים נדרשים להתחבר לאזור האישי במערכת על מנת להנות מהאפשרויות המתקדמות של ניהול הדירות שלהם.

ניהול דירות: מפרסם יכול לצפות, לערוך ולמחוק את הדירות שפרסם.

הוספת דירה חדשה: מפרסם יכול להוסיף דירות חדשות לפרסום.

העלאת תמונות לשרת: כאשר מפרסם מוסיף דירה חדשה, התמונות מועלות לשרת בעזרת אובייקט FormData המועבר כבקשה.

העלאת התמונות מתבצעת על ידי יצירת אובייקט FormData שכולל את פרטי הדירה והתמונות, ולאחר מכן שליחתו לשרת לצורך שמירה בבסיס הנתונים.

טכנולוגיות הפרויקט:
צד שרת:
                                                                                                                      Node.js - המערכת מבוססת על Node.js כשרת Backend.

ספריות נוספות:

                                                                                                                                           Mongoose: עבודה עם MongoDB.
                                                                                                                          
                                                                                                                                    Express: Framework לניהול routing.
                                                                                                                          
                                                                                                                                      Body-parser: ניתוח נתונים מהבקשות.
                                                                                                                          
                                                                                                                                            dotenv: לניהול משתני סביבה.
                                                                                                                          
                                                                                                                                      CORS: ניהול הרשאות גישה בין דומיינים.
                                                                                                                          
                                                                                                                          JWT: ניהול אימות משתמשים בעזרת JSON Web Tokens.

בסיס נתונים:
                                                                                                                        MongoDB Cloud - מערכת ניהול נתונים מבוססת MongoDB.

צד לקוח:
React - פיתוח אפליקציית Frontend עם React.

Redux Toolkit: ניהול סטייט בצורה אופטימלית.

עיצוב מינימלי עם חווית משתמש (UX) ברורה ומזמינה.
